## 🤝 贡献指南

欢迎推荐优质开源项目！推荐的项目需要符合：

- ⭐ 有口碑：有一定 Star 数和社区认可度
- 🔄 有维护：近一年内有维护记录，项目未归档
- 👍 真的好用：同类项目中有特色或优势
- 📜 开源协议：使用 OSI 批准的开源协议

推荐方式：直接 **提交 Issue** 或 **Pull Request** 即可，推荐模板：

```
- [owner/repo](https://github.com/owner/repo) —— 一句话介绍项目亮点
```
